# Deploying Cashwise on Render

One Render web service runs everything: it builds the React site and serves it from FastAPI,
so the website and the API share one address (for example `https://cashwise.onrender.com`).

Files this uses (all in the project root):

| File | What it does |
|---|---|
| `Dockerfile` | Builds the frontend, installs the backend, starts uvicorn on Render's port |
| `.dockerignore` | Keeps `.env`, `storage/`, `venv/` and `node_modules/` out of the image |
| `render.yaml` | Tells Render how to create the service and which settings it needs |

## 1. Check the repository

Your GitHub repo should look like this at the top level:

```
app/  scripts/  data/  frontend/  requirements.txt  Dockerfile  .dockerignore  render.yaml
```

- `frontend/package-lock.json` must be committed (the build uses it).
- `data/` must be committed (the demo business is built from it).
- `.env` and `storage/` must NOT be committed. Check `.gitignore` has both.

Commit and push:

```
git add .
git commit -m "Add Render deployment"
git push
```

## 2. Create the service

1. Go to https://dashboard.render.com and sign in with GitHub.
2. Click **New > Blueprint**.
3. Pick your Cashwise repository. Render reads `render.yaml` and shows one service, `cashwise`.
4. It asks for the two secret values. Paste them:
   - `GROQ_API_KEY`: from https://console.groq.com/keys
   - `HINDSIGHT_API_KEY`: from your Hindsight Cloud dashboard
5. Click **Apply**. The first build takes about 5 minutes. Watch the **Logs** tab.

`JWT_SECRET` is generated by Render for you. `APP_URL` is not needed: the app uses
Render's own address automatically.

## 3. Check it works

1. Open `https://<your-service>.onrender.com/api/health`. You should see
   `"ai_configured": true, "memory_configured": true`.
   If either is `false`, that key is missing or wrong: fix it under **Environment** and save
   (Render redeploys by itself).
2. Open `https://<your-service>.onrender.com`, click **Just looking? Open the demo business**.
3. Ask the agent "Can I pay Vertex on Friday?". It should answer using memories.
   If memories are empty, run this once from your laptop (same Hindsight key in your `.env`):
   `python -m scripts.load_memory`

## 4. Good to know

- **Free plan sleeps** after 15 minutes with no visitors; the next visit takes about 30 seconds.
  Open the site a minute before you present.
- **Free plan has no disk.** Accounts and uploads are wiped on each restart or redeploy.
  The demo business is rebuilt automatically every time, and memories in Hindsight are never lost.
  To keep data: change `plan: free` to `plan: starter` in `render.yaml`, uncomment the `disk:`
  lines, and push.
- **Every push to GitHub redeploys** the site automatically.

## 5. Optional: Google and GitHub sign-in

Do this after the site is live, because the providers need its address.
Callback URLs:

```
https://<your-service>.onrender.com/api/auth/oauth/github/callback
https://<your-service>.onrender.com/api/auth/oauth/google/callback
```

Create the apps as described in `BACKEND.md`, then in Render go to **Environment** and add
`GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`.
Save, and the buttons start working after the redeploy.

## 6. Optional: email reports to management

Reports can always be printed, shared as a read-only link, or opened in your own email app.
To let Cashwise send emails itself (and send scheduled reports), add these under **Environment**:

| Variable | Gmail example |
|---|---|
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | `you@gmail.com` |
| `SMTP_PASSWORD` | a Gmail **app password** (Google Account > Security > 2-Step Verification > App passwords) |
| `SMTP_FROM` | `Cashwise <you@gmail.com>` |

Outlook (`smtp.office365.com`), Zoho Mail (`smtp.zoho.in`), Brevo or SendGrid work the same way.
For port 465 also set `SMTP_SSL=true`.

Scheduled reports run inside the web service. On the free plan the service sleeps when nobody visits,
so a scheduled report is made the next time it wakes up (once, not once per missed run).
For reports exactly on time, use a paid plan, or have a free uptime checker open `/api/health` every 10 minutes.

## Run the same container on your own computer (optional)

With Docker Desktop installed:

```
docker build -t cashwise .
docker run -p 8000:8000 --env-file .env cashwise
```

Then open http://localhost:8000.
